# Bath Emporium + Castle Kitchens: design prototype

Live preview: https://hemantcts.github.io/bathemp-castle-prototype/ (start page = list of every template and the live
addresses it keeps). For client approval of the new design and online store; not the live sites (every page is noindex,
robots.txt blocks crawling, and no link leads to bathemp.ca or castlekitchens.ca).

- `bathemp.html`, `castle.html`: homepages (client mockup + kohler.ca direction).
- `be-*.html`, `ck-*.html`: one file per template, all generated by `tools/build.py` (same head, favicon, scripts).
- `assets/site-*.js`: menus, footer, homepage products. Links are written as the LIVE address they will keep.
- `assets/group.js`: header, mega menu, footer, address map (live address -> template), cart / wishlist in this browser,
  pop-ups. `assets/pages.js`: the page templates. `assets/content-*.js`: real content exported from the live sites.
- Run locally: `python -m http.server 5174` in this folder.
